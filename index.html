GP-200 Patch Manager

Early test build: read-only backup over Web MIDI. Chrome or Edge only.

1. Connect

Close Valeton's editor and any other GP-200 tool first; only one program can use the pedal at a time.

Not connected

2. Back up

Empty From starts at 1A; empty To runs to 64D; both empty is all 256. One slot gives a .prst, more give a .zip.

    3. Restore (test build: writes to the pedal)

    Pick one or more .prst files, or one .zip. They fill consecutive slots from the starting slot. Nothing is written until you confirm. Each patch is read back and checked after writing. Keep this tab in front while writing: browsers slow down pages in background tabs.

    FilePatchSlotReplacesResult

      Developer: write-timing test (scratch slots 64A-64D only)

      Shown only when the page is opened with ?dev. Pick 1-4 patches for set X and the same number of different patches for set Y; patch 1 goes to 64A, 2 to 64B, and so on. Each write switches a slot to whichever set it doesn't hold, so every write changes it, and each is verified like a restore. A late check re-reads every write again after the test has moved on (the pedal can change a byte after the verify): at the end, plus before each overwrite or two writes later if chosen below. Afterwards, restore your 64A-64D backup.
