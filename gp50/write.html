GP-50 write test

An experiment, separate from the GP-200 app. It writes to the pedal, each time after you confirm. Chrome or Edge on a computer. Close Valeton Suite first, and leave the pedal alone while it works.

1. Connect

Not connected.

2. Reference

Not chosen.

3. Read all 100 slots and compare (read only)

4. Write

Each needs a check that matched, since connecting and since the last write (putting back: any complete check). Every patch is read back and compared; the first problem stops it.

Result

Nothing done yet.

A patch whose acknowledgement doesn't come within 1 s is started again (up to 3 times); the log says so.

If a write stops on a problem: save the log, unplug the pedal and plug it back in, Connect, and check again before anything else.
